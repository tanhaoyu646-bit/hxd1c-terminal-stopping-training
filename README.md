# HXD1C 终到对标停车虚拟实训

这是从已验收的“途中调速”驾驶框架派生出的独立项目，聚焦旅客列车进入终到站后的单次空气制动精准对标。

## 首版范围

- 标准旅客列车，采用原游戏内宜宾—内江线路的大山铺站Ⅰ道、原约 500 m 站台、原地形和站场沿线对象；停车位置标设置在站台有效范围内。
- 训练基线采用微课中的“40 km/h、50 kPa、约280 m标准制动距离”；30 km/h时距标约120 m、20 km/h时距标约50 m。停车制动先施行初减，列车稳定降速约5秒后再逐级退回牵引手柄至零位。
- 速度每高于40 km/h约1 km/h，选定制动距离增加约20 m；需要追加时，追加减压量不得超过初次减压量。
- 教学模式在制动力判断、起闸、30/20 km/h观速和侧窗对标节点冻结讲解且不生成成绩；考评模式隐藏答案并评分。
- 进入项目先填写姓名和学号；信息只保存在本项目当前浏览器会话，并写入本轮成绩单。
- 复用“途中调速虚拟实训系统”已调试的 HXD1C 操纵台级位、动态速度／风压表、机车信号、LKJ 原机界面与 CIR 原模拟器；站台、地形、接触网、建筑、植被和线路设备取自原游戏场景，仅新增教学停车位置标、距离参照和停车评分状态机。
- 初始位置位于进站信号机外方约500 m；进站信号显示一个黄灯，越过后LKJ左上角机车信号转红黄灯。
- 牵引手柄正级位按途中调速项目作为目标速度给定，4级对应40 km/h，达到给定速度后自动卸载；LKJ在进站信号机处将线路限速由80 km/h切换为站内45 km/h。
- 手机端只装载大山铺终到站场裁剪资源，并且仅生成 `27900–30550 m` 站场窗口内的轨道几何；场景加载完成后才启动列车和考核计时。移动端与途中调速项目使用相同的抗锯齿、1.15像素比和纹理各向异性基线。

“40 km/h、50 kPa、280 m”是本场景标准制动力模型，不是所有车型、编组、坡道和站场的统一参数。实际作业应结合贯通试验、车底、编组和所属单位操纵规定。

## 本地运行

```powershell
npm run serve
```

访问 `http://127.0.0.1:4193/`。三维线路资源使用 `fetch()` 加载，不能直接双击 HTML 文件运行。

## 操作

- 桌面端：驾驶台左下为自阀和单阀，中下偏右为牵引／电制动手柄，中央屏幕为 LKJ，右侧窄屏设备区为 CIR。手柄上下拖动换位，点击状态框可逐级换位；单阀向右滑动并保持为单缓，松手自动回位；双击牵引手柄或按数字键 0 回零。
- 手机横屏：可直接拖动同一套驾驶台手柄，也可点顶部“操作”打开途中调速项目同款操作面板；面板提供牵引、自阀、单阀及 LKJ/CIR 入口。
- CIR 已恢复途中调速项目的原模拟器和列尾风压联动，但终到对标评分不要求操作 CIR；它用于设备熟悉，不作为额外得分项。
- 键盘：数字键 0 牵引回零，↑/↓ 调整自阀，Esc 关闭面板。

## 满分操作基线

1. 登记姓名和学号，选择教学模式或考评模式；只有考评模式生成成绩。
2. 点击驾驶台中央 LKJ 打开放大界面，确认进站信号为一个黄灯；随后点击顶部“呼唤确认”。
3. 初始距进站信号机约500 m、牵引4级给定40 km/h；通过进站信号机时不得超过45 km/h，起闸时保持适当低牵引。
4. 越过进站信号机后机车信号转红黄灯。本场景停车标至出站信号机约120 m，标准制动距离280 m，因此LKJ距出站约400 m、速度约40 km/h时自阀置初制位，形成约50 kPa初减压；稳定降速约5秒后逐级退回牵引手柄，接近零位稍作停留后回零。
5. 初减后 80 m 内，将单阀向右滑动并短暂保持完成单缓，随后松手回位；不要在运行中把单阀置制动级位。
6. 速度降至30 km/h时，距停车标应约120 m；若距离明显偏小，待排风停止后适时追加一级，追加量不得超过初次减压量。
7. 速度降至20 km/h时，距停车标应约50 m；继续使用列车空气制动低速对标，避免频繁追加或缓解。
8. 停车误差控制在 ±0.5 m、最大减速度不超过 0.7 m/s²。停稳后自阀再追加 1 级至常用Ⅲ，并将单阀置 5 级全制动；保持到列车管实际减压达到 100 kPa 以上，系统自动完成本轮。

## 验证

```powershell
npm run check
```

自动测试覆盖教学基线、学员信息、黄灯停车进路、初始位置、训练与考核隔离、标准满分轨迹、越标安全红线、动力制动/运行中单阀违规记录、换向联锁、12级牵引手柄、原操作台档位贴图、LKJ原机界面、CIR入口与单缓逻辑、手机裁剪资源、远景钢轨鼓包回归，以及原站台里程、站场窗口和 129×129 原地形资产完整性。

若原线路场景重新导出，先运行 `npm run assets:terminal` 重新生成终到站专用裁剪场景和预对齐线路，再运行 `npm run check`。

## 独立性

- 独立目录、独立 Git 仓库、独立包名和服务端口 `4193`。
- 运行状态存储键仅使用 `hxd1c-terminal-stopping-v1` 前缀。
- 学员会话键独立使用 `hxd1c-terminal-stopping-candidate-v1`。
- 不引用来源项目相对路径，运行时不读取或写入其他项目。

专业依据与参数边界见 [PROFESSIONAL_BASIS.md](PROFESSIONAL_BASIS.md)，评分细则见 [ASSESSMENT_SPEC.md](ASSESSMENT_SPEC.md)。
