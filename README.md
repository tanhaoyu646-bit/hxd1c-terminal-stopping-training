# HXD1C 终到对标停车虚拟实训

这是从已验收的“途中调速”驾驶框架派生出的独立项目，聚焦旅客列车进入终到站后的单次空气制动精准对标。

## 首版范围

- 标准旅客列车、平直站场、停车位置标距出站信号机 100 m。
- 训练基线采用“40-400-100-30”：约 40 km/h、距停车标 400 m 初减压；距标 100 m 时以约 30 km/h 作为追加判断参照；距标 50 m 进入低速对标。
- 初减压基线 50 kPa，追加一般不超过两次、单次追加不超过初减量；少量减压停车后追加至 100 kPa 以上并以单阀全制动防溜。
- 教学训练显示距离标记、参考速度带和条件式提示；独立考核隐藏答案，仅保留过程记录、运行曲线和评分。
- 复用 HXD1C 操纵台、自阀、单阀、单缓、牵引手柄、LKJ 与线路三维框架；新建站台、停车位置标、出站信号机和停车评分状态机。

“40-400-100-30”是本工况的经验模型，不是所有车型、编组、坡道和站场的统一规章参数。制动力、坡道、风速、黏着条件和列车编组变化时，应使用所属单位操纵示意图、提示卡和现场规定。

## 本地运行

```powershell
npm run serve
```

访问 `http://127.0.0.1:4193/`。三维线路资源使用 `fetch()` 加载，不能直接双击 HTML 文件运行。

## 操作

- 桌面端：拖动驾驶台牵引手柄、自阀和单阀；点击状态框可逐级换位。点击驾驶台中央 LKJ 可放大操作。
- 手机横屏：底部提供牵引回零、自阀增减、单缓、停车后单阀全制、呼唤和 LKJ 大按钮。
- 键盘：`0` 牵引回零，`↑/↓` 自阀增减，`Esc` 关闭面板。

## 验证

```powershell
npm run check
```

自动测试覆盖教学基线、训练与考核隔离、标准合格轨迹、越标安全红线，以及动力制动/运行中单阀违规记录。

## 独立性

- 独立目录、独立 Git 仓库、独立包名和服务端口 `4193`。
- 浏览器存储键仅使用 `hxd1c-terminal-stopping-v1` 前缀。
- 不引用来源项目相对路径，运行时不读取或写入其他项目。

专业依据与参数边界见 [PROFESSIONAL_BASIS.md](PROFESSIONAL_BASIS.md)，评分细则见 [ASSESSMENT_SPEC.md](ASSESSMENT_SPEC.md)。
